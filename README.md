# 🚗 Sistema de Estacionamento

> Repositório principal do projeto de gestão e controle de estacionamentos.

---

## 📌 Sobre o Projeto

O **Sistema de Estacionamento** foi desenvolvido para automatizar e otimizar o controle de veículos, gerenciando entrada, saída, tempo de permanência e cálculo de tarifas de forma simples e eficiente.
